# Multi-Agent Research Assistant 🤖

A Python-based multi-agent system that uses LLM-powered agents (Researcher, Analyst, Writer) to collaboratively research a topic and generate a structured report.

## Features
- Multiple collaborating AI agents
- Graph-based execution flow
- Local LLM support via Ollama
- Modular and extensible design

## Tech Stack
- Python
- LangGraph
- LangChain
- Ollama
- GitHub
